# Vector Store Temporal

This directory contains examples and resources related to temporal (time-based) vector store use cases in Teradata. The content here demonstrates how to create, manage, and query vector stores with temporal data, including:

- Example datasets (e.g., `commercial_real_estate.csv`)
- Notebooks for creating and querying temporal vector stores (e.g., `Create.ipynb`, `temporal_sql.ipynb`)
- Data model and visualization images (e.g., `VSData1b.png`, `VSDataModel2.png`)

## Notebooks
- **Create.ipynb**: Steps to create a temporal vector store.
- **temporal_sql.ipynb**: SQL-based operations and queries for temporal vector stores.

## Data
- **commercial_real_estate.csv**: Sample dataset for temporal vector store examples.

## Images
- **VSData1b.png, VSDataModel2.png**: Visualizations and data models for temporal vector store use cases.
